# Bedaag — The Dry Cleaners

> **Pristine, Spotless & Unblemished Fabric Care Delivered to Your Doorstep.**  
> Gurugram & Delhi NCR's premier on-demand garment care service.

---

## ✨ Features

- **Sleek, App-like Design System:** Built with deep navy (`#0A192F`), laundry cyan (`#0EA5E9`), glassmorphism sticky header, and Plus Jakarta Sans typography.
- **Hero Quick Booking Widget:** Instant scheduler with mobile number validation, Gurugram sector dropdown, and service type picker.
- **Interactive Rate Card & Live Bill Estimator:**
  - Real-time `+` / `-` quantity counters for Men's, Women's, Winter/Ethnic, Shoes & Bags, and Household items.
  - Live sticky cart with animated **Free Doorstep Pickup** progress bar (unlocks above ₹499).
  - Direct "Proceed to Schedule" action carrying all selected items into checkout.
- **Interactive Before & After Comparison Slider:**
  - Draggable split-slider (mouse & touch) with real stain removal presets (pure silk curry/wine stain, muddy sneaker restoration).
- **Gurugram Sector Coverage Checker:**
  - Live search with instant feedback and next pickup slot estimates across DLF, Golf Course Road, Nirvana Country, and all sectors.
- **Multi-Step Booking Modal & Receipt:**
  - Full scheduling with name, phone, address, and 2-hour morning/afternoon/evening slots.
  - Confetti celebration and `#BDG-XXXX` realistic booking confirmation with WhatsApp sync.
- **Photorealistic Indian Assets:** Doorstep delivery concierge, luxury bridal atelier, sneaker clinic, and leather spa studio.

---

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Icons:** [lucide-react](https://lucide.dev/)
- **Visuals:** Canvas Confetti for celebratory receipts
- **Styling:** Modern Vanilla CSS design system with custom properties and CSS Grid/Flexbox

---

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/kushal945/bedaag-web.git
cd bedaag-web

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
